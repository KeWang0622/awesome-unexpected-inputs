# Visual credits

[Collection](../README.md)

The hero and six workflow cards are **conceptual illustrations**, not project screenshots, installation evidence or photographs of tested hardware. Text labels and primary sources carry the factual claims.

| Asset | Origin and treatment | Terms |
| --- | --- | --- |
| `cover.png` | Original editorial illustration generated with OpenAI's built-in image generation tool on 2026-10-26; text-to-image mode; exact prompt in [cover-prompt.txt](cover-prompt.txt) | Included with the catalog's CC0 dedication to the extent rights exist |
| Six project SVGs | Original vector diagrams authored in `scripts/catalog.py`, generated from reviewed spotlight records; no third-party visual traced or embedded | CC0 |
| Awesome badge | Linked badge from [Awesome](https://awesome.re) | External asset |
| Workflow and license badges | Live external GitHub Actions / Shields badges | External services; not device-test evidence |

The repository does not bundle upstream photos or demo videos. A catalog `media_url` links to its original publisher; its `media_note` records provenance and known reuse limits. Linking a demo does not transfer a license or establish that we reproduced it.

Regenerate cards with `python3 scripts/catalog.py build`. Supply both useful alt text and a nearby text description; never make the image the only place a requirement appears.
